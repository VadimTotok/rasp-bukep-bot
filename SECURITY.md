# Безопасность

## Почему проверка TLS для `rasp.bukep.ru` отключена?

Сайт `rasp.bukep.ru` использует TLS-сертификат, выданный российским
удостоверяющим центром (Russian Trusted Root CA / Минцифры). Этот
корневой CA **отсутствует** в стандартных хранилищах доверенных
сертификатов большинства ОС, поэтому обычная проверка даёт ошибку:

    SSL certificate problem: unable to get local issuer certificate

Мы осознанно отключаем проверку **только** для этого домена:

1. **Данные публичны.** Расписание вуза не секрет, оно и так
   на открытом сайте.
2. **HTML-инъекция закрыта.** Все данные с сайта проходят через
   `esc()` перед вставкой в сообщения Telegram. Подменённый ответ
   не может внедрить теги или ссылки.
3. **Ущерб от MITM ограничен.** Максимум студент увидит неверное
   расписание. Это неприятно, но не утечка данных и не фишинг.

Проверка отключена **только** для `rasp.bukep.ru`. HTTP-клиент не используется для других доменов.

## Что делать, если хотите включить проверку

Если вы администратор и можете исправить сертификат сайта то сделайте
это :^) После этого в `src/bukep_bot/config.py` поменяйте:

    RASP_VERIFY_SSL = True
